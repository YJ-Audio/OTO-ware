# OTO-ware / YJ Audio

ワンノブのハードクリッピング・エフェクト、試作 v0.2。VST3 / Standalone、モノラル / ステレオ対応。

## 操作

ノブを右へ回すとザラッと強く歪みます。0%は原音、100%は最大。ダブルクリックで0%へ戻ります。数値入力とDAWオートメーション、セッション保存に対応します。

信号経路：入力 → LOW BOOST（約180 Hz以下） → 最大+36 dBのドライブ → 対称ハードクリップ → 最大−6 dBの出力補正 → 原音とのミックス。
0〜25%で原音から歪み音へ移行し、25〜100%は歪み音のみです。ノブは20 msで平滑化し、左右は同じ係数で独立処理します。遅延0サンプル。

`LOW BOOST` は0〜+12 dBで、約180 Hz以下の低域を歪みの前段で持ち上げます。WAREを0%にしても低域ブースト単体で使えます。低域のピークも増えるため、DAWの後段でレベルを確認してください。

出力補正は固定カーブで、知覚音量の完全な一致を保証するものではありません。0%では入力のピーク超過もそのまま通します。試作はオーバーサンプリングなしのハードクリップで、高域に折り返し成分が生じます。音色の試聴後に調整する前提です。
